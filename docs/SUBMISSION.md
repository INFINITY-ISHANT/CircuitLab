# Submission

## Short description

Finding which parts of a neural network implement a behavior (a circuit) is a core task in mechanistic interpretability, and it is slow: the standard approach patches every component by hand. CircuitLab asks whether a team of AI agents can run that search under an explicit compute budget, with every forward pass counted.

We built a lab around GPT-2 small and the indirect object identification (IOI) task. A TransformerLens toolkit provides activation patching, mean ablation, two-stage path patching and faithfulness scoring with a same-size random-circuit control. A planner and six specialist agents on Omnigent (literature scout, task designer, hypothesis, experimentalist, analyst and safety) share one tool server and one forward-pass counter. Guardrails keep a human in charge: a person must approve every final claim and any sweep over 24 heads, and a hard spend cap stops the models.

What works today: exhaustive patching of all 144 heads costs 292 forward passes and puts 8 published circuit heads in its top 10. In our best agent run the agents found the three name movers (L9H9, L10H0, L9H6) with faithfulness 0.8827 against 0.0275 for a random circuit, after a human approved the claim, using 366 passes. We also report where it falls short: the agents did not beat the exhaustive baseline on passes, recall is 3 of 26 published heads, and a later run that hid the IOI paper ended before presenting a claim. A new joint-only path-patching mode and a limit of 24 hand-picked senders make an upstream trace cheaper (about 8 passes per sender instead of about 28).

Researchers who want to map a behavior cheaply, and anyone studying how far agents can run honest, auditable science, benefit. Every experiment, including the failures, is logged in a research record that can be replayed.
